# Proyecto Integrador 0

*Sprint Analítico:* 
La coordinación de la carrera nota que los estudiantes se quejan frecuentemente de "fallas en la plataforma", pero nadie sabe exactamente cuál es el problema real. El director quiere tomar una decisión: ¿Debe contratar más servidores, capacitar a los docentes o rediseñar la interfaz de la plataforma?

- Como equipo de ingeniería, se te pide diseñar la estructura de datos inicial que nos permita registrar los reportes de falla para responder a la consulta estratégica: *¿Cuál es el tipo de falla más frecuente por departamento académico y cuál es su tiempo medio de resolución?*

*Instrucciones*
1. Identifica y define una tabla llamada `reportes_soporte`
2. Escribe una lista con mínimo 6 campos/columnas esenciales para esta tabla.
3. Para cada campo especifica:
    - Nombre de la columna (en formato `snake_case`).
    - Tipo de dato genérico (`TEXT`, `INTEGER`, `TIMESTAMP`, `BOOLEAN`, `FLOAT`).
    - Breve justificación de por qué ese dato ayuda a responder a la pregunta del director.
